# CRISPR pgBoost reference

This directory contains the paper-era GRCh38 K562 CRISPR benchmark used by
Dorans et al. (Nature Genetics, 2025) and the 1000 Genomes SNP BED distributed
with pgBoost.

- `EPCrisprBenchmark_ensemble_data_GRCh38.tsv.gz`: tested K562 regulatory
  element--gene links from the historical EngreitzLab benchmark.
- `SNPs.bed.gz`: pgBoost SNP universe.
- `crispr_new_snp_gene_benchmark.tsv.gz`: generated by intersecting the two
  files with `scripts/prepare_crispr_new_reference.R`.

The downloaded table has 10,412 rows; after requiring a binary `Regulated`
label, 10,411 tested K562 links remain (487 positive and 9,924 negative).
Counts in an individual EpiLink dataset can differ because only links whose
enhancer interval overlaps that dataset's tested ATAC peaks are assessable.

Positive labels use `Regulated == TRUE`: adjusted p-value below 0.05 and a
negative expression effect after CRISPRi repression. Other tested links are
treated as tested-but-not-validated negatives; the single element--gene row
without a `Regulated` label and rows without a TSS (needed for the pgBoost
distance thresholds) are excluded.

## Run

From the EpiLink project root:

```bash
# Only needed if the two raw reference files are absent or need refreshing.
bash scripts/download_crispr_new_reference.sh

Rscript scripts/prepare_crispr_new_reference.R
Rscript scripts/run_crispr_pgboost_validation.R XuK562 --n-bootstrap=200
Rscript scripts/plot_crispr_pgboost_validation.R XuK562
```

The validation runner evaluates `>1 kb`, `>10 kb`, and `>100 kb` links using
`-log10(raw p-value)` as each method's ranking score. It reports AUPRC,
average enrichment (AUPRC divided by the positive prevalence), enrichment-
recall curves, and a top-5% one-sided Fisher enrichment analysis. `All` takes
the maximum score for each SNP--gene pair across the available cell types.

Outputs are written under
`results/validation/CRISPR/CRISPR_pgBoost/`; figures are PDF-only under its
`figures/` subdirectory.  FlowFISH and EPCrispr use the sibling directories
`CRISPR_FlowFISH/` and `CRISPR_EPCrispr/`.

For the interval-level Fisher test (the `CRISPR` validation folder), use the
same EPCrispr table directly:

```bash
Rscript scripts/run_crispr_validation.R XuK562 --reference=engreitz
## SatpathyK562 is intentionally not part of the current benchmark run.
```

This writes both `correction_F` and `correction_T` unless
`--correction=F` or `--correction=T` is supplied.  The legacy FlowFISH test is
still available with `--reference=flowfish`; FlowFISH is now cell-type aware
and should be used for PBMC/BMMC, whereas Engreitz is K562-only.
