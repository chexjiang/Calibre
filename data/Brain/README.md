# Brain multiome benchmark input

This directory contains the Brain dataset used by Sakaue et al. (2024) for
SCENT. The source is the processed human grey-matter control multiome object
from Meijer et al. (2022), distributed through GEO subseries GSE193240 under
the GSE166179 SuperSeries.

Source file:

`GSE193240_HS_GM_Ctrl_multiomics_UCSC.rds.gz`

The preprocessing script selects the three cell labels represented in the
Sakaue Brain panel and reproduces its exact total of 4,272 nuclei:

| exported `newCT` | source label | cells |
| --- | --- | ---: |
| Excitatory neurons | `EXCNEU_CTR` | 607 |
| Astrocytes | `ASTRO_CTR` | 793 |
| Oligodendroglia | `OLIGO_CTR` | 2,872 |

The source object already contains RNA/ATAC QC metrics and a precomputed WNN
UMAP. No additional QC threshold is applied. The exported ATAC matrix uses the
source `ATAC` assay (hg38, 110,756 shared peaks) and raw counts. A cell-type-
specific peak list is not required: all three cell types remain in one common
peak-by-cell feature space, and `Brain.gene_peak_df.rds` contains the shared
cis candidate pairs generated from +/-500 kb gene windows.

Files generated by `data_preprocessing.R`:

- `Brain.rna.rds`: raw gene-by-cell RNA counts
- `Brain.atac.rds`: raw peak-by-cell ATAC counts
- `Brain.meta.rds`: cell metadata, QC fields, `newCT`, `celltype`, and log count covariates
- `Brain.gene_peak_df.rds`: `gene`/`peak` candidate pairs
- `Brain.celltype_counts.tsv`, `Brain.qc_summary.tsv`, `Brain.wnn_umap.png`: validation outputs

References: [Sakaue et al. (2024)](https://doi.org/10.1038/s41588-024-01682-1),
[Meijer et al. (2022)](https://doi.org/10.1016/j.neuron.2021.12.034),
[GEO GSE166179](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE166179),
